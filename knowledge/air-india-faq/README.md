# Air India FAQ knowledge collection

`corpus.json` is the source manifest for the 17 FAQ-index topics plus four adjacent travel-service sources: baggage guidelines, help/contact, flight status, and online check-in information. It contains source metadata and research summaries; it is not the full knowledge corpus. The local FAQ UI currently has 48 curated Q&A summaries.

The ingester at `scripts/ingest_faq.py` combines this manifest with `additional-sources.json`. The cargo landing page is a directory, so the manifest indexes its linked FAQ and product pages. It also includes the official restricted-baggage and disability guides and the Conditions of Carriage PDF. Extraction keeps each FAQ answer with its question and records the physical PDF page for each passage. `--dry-run` reports source coverage and writes a snapshot only when all required sources pass the extraction checks.

The coverage report verifies extraction and `retrieval-eval.json` checks that a staged index can retrieve expected passages before publishing. A separate editorial review still matters for conflicting or time-sensitive policies. For example, the check-in FAQ contains both a general 60-minute cutoff and an answer that distinguishes domestic and international flights. The chat should preserve those distinctions and avoid inventing a universal deadline. Sources older than 90 days are excluded from retrieval.

The index and source pages were reviewed on 2026-11-04. The user-provided baggage and help paths were not accessible at review time; the current Baggage Guidelines and Contact Us pages were used as their equivalents. The provided web-check-in path was also unavailable; the current `web-checkin` page was used. The FAQ and dedicated web-check-in pages report different cutoffs for online check-in; the corpus flags this rather than merging them. Source URLs live only in this local research corpus for provenance; they are not rendered by the FAQ UI.
